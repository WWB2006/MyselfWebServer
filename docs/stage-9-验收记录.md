## 四、故障注入

```bash
python3 scripts/fault_injection.py --host 127.0.0.1 --port 8080
```

| 场景 | 期望行为 | 实际结果 |
| --- | --- | --- |
| 半包请求（先发一半，再补其余） | 正常返回 200，不误判 |  |
| 粘包请求（一次发两条） | 两条都被处理 |  |
| 慢连接（连上不发数据） | 空闲超时后被断开 |  |
| 超长请求头（>8KB） | 返回 4xx 并关闭，服务不崩溃 |  |
| 超长请求体（>1MB） | 返回 4xx 并关闭 |  |
| 连接抖动（快速建立断开 200 次） | 无 fd 泄漏，服务存活 |  |

## 五、过载保护与优雅退出

| 检查 | 命令 | 期望 | 实际 |
| --- | --- | --- | --- |
| 过载返回 503 | `-m 8` 后并发开 20 条连接 | 超出部分收到 503 或被立即关闭 |  |
| 拒绝计数 | `curl -s .../metrics \| grep rejected` | 数值与拒绝次数一致 |  |
| 优雅退出 | 压测中按 Ctrl+C | 日志出现 "shutdown requested"，进程正常退出，日志落盘完整 |  |
| 退出后无残留 | `ss -tn state established \| wc -l` | 连接全部关闭 |  |
