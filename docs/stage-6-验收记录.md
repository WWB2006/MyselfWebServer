## 二、功能验收

| 序号 | 检查项 | 命令 | 期望结果 | 实际结果 |
| --- | --- | --- | --- | --- |
| 1 | 默认级别 | 不加 `-l` 启动 | 只出现 INFO 及以上日志 |  |
| 2 | 级别过滤 | `-l warn` 启动并压测 | 看不到 accept/http/close 这类 INFO 日志 |  |
| 3 | 调试级别 | `-l debug` 启动 | 能看到 epoll add 等 DEBUG 日志 |  |
| 4 | 日志格式 | 观察任意一行 | 形如 `20260926 20:15:03.123456 [INFO ] message - main.cpp:123` |  |
| 5 | 线程可区分 | `-t 4` 下压测 | 日志里能通过线程 id 区分不同 IO 线程 |  |
| 6 | 异步落盘 | `-g logs` 启动 | `logs/` 下出现 `server.YYYYMMDD-HHMMSS.pid.log` |  |
| 7 | 文件轮转 | `-s 1` 启动并压测 | 超过 1MB 后出现新的日志文件 |  |
| 8 | 控制台关闭 | `-q` 启动并压测 | 终端没有输出，日志只写文件 |  |
| 9 | 危险错误不丢 | `-l error` 下制造一次连接错误 | 立即看到 ERROR 日志（同步输出到文件与控制台） |  |
| 10 | 退出落盘 | Ctrl+C 前日志完整 | 最后几条日志已写入文件 |  |
