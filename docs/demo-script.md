# 三到五分钟演示视频分镜脚本

目标：让面试官在五分钟内看懂"你做了什么、怎么做的、结果如何"。全程录屏加旁白，
不要出现密钥、密码、真实公司信息。

## 录制前准备（十分钟）

1. 服务端用 `Release` 构建，终端字号调到 16 号以上，关闭无关窗口与通知；
2. 预开三个终端：`A 服务端`、`B 压测/验证`、`C 日志/指标`；
3. 提前跑一次完整流程确认没有报错，把要执行的命令写进笔记，避免现场敲错；
4. 录屏分辨率 1080p，麦克风测试一遍音量。

| 时间 | 画面 | 操作 | 旁白要点 |

## 讲解口径（避免踩坑）

1. **说清"参考"与"自研"**：参考了 TinyWebServer 与 muduo 的设计，核心模块自行实现；
2. **数字必须来自本次录制**：不要把文档里的示例数字说成实测结果；
3. **主动说取舍**：例如"定时器没上 timerfd，因为要让任务天然在循环线程执行，代价是精度受循环影响"；
4. **不夸大**：不要出现"百万并发""零延迟"这类无法验证的说法；
5. **留一个可追问点**：视频结尾可以主动提"过载保护用的是立即 503，如果要做排队需要引入队列与背压"，
   引导面试官问你有准备的问题。
