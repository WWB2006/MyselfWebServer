# docs 目录导览

| 路径 | 内容 |
| --- | --- |
| `adr/` | 关键设计决策记录（ADR），一次决定一页，包含背景、选项、决定与代价 |
| `bench/` | wrk 压测原始输出与汇总表，按时间命名 |
| `architecture.md` | 分层、线程模型与一次请求的完整时序 |
| `stage-N-验收记录.md` | 各阶段的环境、命令、输出与验收结论 |
| `demo-script.md` | 三到五分钟演示视频的分镜脚本 |
| `release-checklist.md` | v1.0.0 发布检查清单 |
| `resume-and-interview.md` | 简历条目、讲解稿与高频追问 |

各阶段的验收记录（阶段 0、1、2、3 只有功能与命令清单，阶段 4 起补入性能数据）：

| 文件 | 阶段 | 重点 |
| --- | --- | --- |
| `stage-0-验收记录.md` | 0 工程骨架 | 构建、运行、参数解析、目录结构 |
| `stage-1-验收记录.md` | 1 阻塞式 TCP 服务 | nc 收发回显，并记录单连接阻塞现象 |
| `stage-2-验收记录.md` | 2 非阻塞 epoll | 多连接并发、半包粘包、ET 循环读 |
| `stage-3-验收记录.md` | 3 HTTP 解析与静态文件 | curl 200/404、目录穿越防护 |
| `stage-4-验收记录.md` | 4 主从 Reactor 与线程池 | 连接分散到多个 io 线程、压测基线 |
| `stage-5-验收记录.md` | 5 定时器与空闲超时 | 空闲连接自动断开、定时任务取消 |
| `stage-6-验收记录.md` | 6 日志系统 | 分级、异步落盘、按大小与日期轮转 |
| `stage-7-验收记录.md` | 7 运行指标 | `/api/status` 与 `/metrics` 字段核对 |
| `stage-8-验收记录.md` | 8 测试体系与 CI | ctest 46 例、pytest 15 例、Actions 全绿 |
| `stage-9-验收记录.md` | 9 性能与健壮性 | 压测矩阵、火焰图、六类故障注入、长稳 |

阶段 10 的验收以 `release-checklist.md` 与 `docs/demo-script.md` 为准，不再单列验收记录。

## 写文档的三条约定

1. **决策写 ADR，过程写验收记录。** 决定性的选型进 ADR，一次性的验证过程进验收记录，
   两者不要混在一起。
2. **数字必须可复现。** 任何性能或稳定性数据都要带环境、命令与原始文件路径。
3. **文档与代码同一次提交。** 改完行为就更新对应文档，不要留到“以后统一补”。
