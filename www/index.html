MyselfWebServer 正在运行

基于 epoll ET 与主从 Reactor 的 C++17 高并发 HTTP 服务器

路径说明
/ · /index.html 本页面（静态文件）
/api/status JSON 状态：连接数、请求数、延迟分位、字节数、运行时长
/metrics Prometheus 文本格式指标，含 myself_* 计数器与延迟直方图

命令行验证：
curl -i http://127.0.0.1:8080/index.html
curl -s http://127.0.0.1:8080/api/status
curl -s http://127.0.0.1:8080/metrics
